A newspaper front page for Thursday 19 November 2026, drawn entirely in
code: the Trump–Xi–Putin summit in Shenzhen, Israel's ground operation in
Gaza, the Crimean Bridge hit again, GTA VI's worldwide launch, Anthropic's
record IPO debut, and NASA confirming Voyager 1 one light-day away.

`main.py` (pure Python 3 standard library, no network) draws the 1024x1024
image to `/output/entry.png` — the same bytes on every run.
